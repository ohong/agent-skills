# Name It

Naming is positioning, not labeling. You aren't choosing a word — you're compressing a brand's story, feeling, and promise into one, and a name is the first thing anyone encounters: it buys credibility up front or bleeds it before it's earned. This skill distills Willem Van Lancker's *How to Name Anything in an Afternoon* (bundled, with page pointers), plus the field wisdom of David Placek (Lexicon Branding — BlackBerry, Pentium, Azure, Sonos, Vercel) and A Hundred Monkeys.

## First principles

1. **Orient before generating — always.** Never produce names before knowing, at minimum: what it does, who it's for, and the one feeling it should evoke. Even when the user says "just give me names," ask those three questions first; 60 seconds of orientation transforms output quality.
2. **Volume before judgment.** Great names come from candidate #700, not #7. Generate wide (Lexicon runs 1,000–1,500), evaluate only afterward — premature judgment kills originality.
3. **Comfort is a warning sign.** Distinctive names feel uncomfortable at first (Azure was "dumb," BlackBerry "crazy"). Polarization signals energy; universal mild approval signals forgettable.
4. **No eureka.** Nobody "knows it when they see it" — across thousands of professional projects the aha moment essentially never comes. Score against criteria instead of waiting for goosebumps.
5. **2 of 3 on Memory / Meaning / Range = viable.** 3 of 3 is rare magic; 0–1 gets cut.
6. **A name starts a conversation.** It doesn't need to explain the business; it needs to earn the question that lets the story be told. Needing a story is good; needing an apology is not.
7. **Never let domain availability choose the name.** The .com is an area code, not the address — modifiers and alt TLDs unlock almost any name.
8. **Crowds inform, one person decides.** Groups agree on what's easy to agree on. Structured testing feeds a single decision-maker; committees find the safe middle.
9. **Sound carries meaning before semantics.** Letters have psychological vibrations (B = reliable, V = alive, Z = fast) — use phonetics as a design material, not an afterthought.
10. **The name is 20%; stewardship is 80%.** Names accrue meaning through consistent, confident use — they don't start with it. There is no perfect name, only a name used with conviction.

## A name's four jobs (§ "Four Jobs," PDF p. 7)

1. **Personifies** — sets tone and character (Apple friendly, Microsoft serious)
2. **Encompasses** — one handle recalls the whole experience (Uber: app, black cars, convenience)
3. **Rallies** — internal banner, external billboard; great names yield natural demonyms (Googlers)
4. **Spreads** — enables word-of-mouth ("Google it"); a resonant name is half the marketing

## The pipeline

Six phases. Adapt depth to the user's pace — quick mode compresses Phases 1–3 into one exchange; full mode walks each phase. Exit criteria are non-negotiable in either mode.

### 1. Orientation — know what you're naming (§1, PDF pp. 10–15)
Interview the user (skip what's already answered; the final decision-maker must be in this conversation):
- **Purpose** — what breaks if this doesn't exist? Good answers hurt: specific enough to exclude half the market (Stripe: "increase the GDP of the internet").
- **Promise** — what happens in the first five minutes of use? Must survive contact with reality.
- **Audience** — the primary one. What other brands do they love? (Overlooked and critical — a name collision with a beloved adjacent brand hurts.)
- **Feeling** — ONE dominant emotion (Relief / Momentum / High-Status / Wonder / Rebellion / Belonging / Control). Emotions don't blend; pick.
- **Tonal sliders** — position on Playful↔Serious, Accessible↔Exclusive, Innovative↔Traditional.
- **Non-starters** — forbidden words, vibes, associations (competitor-adjacent, cultural taboos, pharma-sounding, hard to spell over the phone).
- **Competitor landscape** — what's everyone called; where do names cluster; where's open territory.

Capture answers as a compact compass — every later cut cites it. *Exit: compass written.*

### 2. Exploration — flood the page (§2, PDF pp. 16–19) → `generation.md`
Generate 100+ candidates internally across at least six name types (descriptive, experiential, evocative, invented, identity, compound — plus hunt for special wrongness). Use all nine techniques: free naming, bad-names-first, springboards, meaningful facets, lexical rabbitholing, oblique briefs, compounds, sound-first, modification. *Exit: large triaged list (Promising / Interesting / Raw).*

### 3. Distillation — cut ruthlessly (§3, PDF pp. 20–22) → `evaluation.md`
Screen nominations through the six dimensions (Depth, Temperature, Voice, Visual, Differentiation, Special Wrongness), score Memory/Meaning/Range, run reality checks (legal scan, language check, landscape check). *Exit: 12–15 viable names. Fewer than 10 → back to Exploration; more than 20 → raise standards.*

### 4. Validation — perspectives that don't care about feelings (§4, PDF pp. 23–26) → `evaluation.md`, then `finalization.md`
Hand the user run-ready protocols: the 8-second test, stack-rank polling, Placek's competitor test. Run what you can yourself: phonetics fast-pass, mockups in caps/lowercase/fonts and contexts, future-proofing, knock-out trademark search, domain options (use a domain-availability tool if connected). *Exit: 3–5 finalists that passed every test. Don't settle.*

### 5. Commitment — one person decides (§5, PDF pp. 27–29) → `finalization.md`
Assemble a decision brief per finalist (evidence, legal, domains, case for/against). Recommend the phone-wallpaper test or a 45-minute structured meeting with secret ballot and CEO veto. Same-day lock-in: trademark filing, domains, handles, name story. Have regret counsel ready — post-decision doubt is predictable, not a signal. *Exit: one name, locked in.*

### 6. Stewardship — own what you named (§6, PDF pp. 30–31) → `finalization.md`
Founding myth, total consistency (no apologetic taglines), family naming for products, trademark protection. Names compound: Nike means victory through decades of use.

## Interaction protocols

**Quick mode** (user wants names now): ask the three minimum orientation questions, then deliver one curated batch. Still generate wide internally; still score before presenting.

**Evaluating an existing name**: run it through the six dimensions and Memory/Meaning/Range *before* offering alternatives. Give an honest verdict with the scores; sentimentality is the enemy.

**Presenting candidates**:
- Group by name type, 3–6 per group; format as **Name** — one-line rationale tied to the compass. Let names breathe — over-explaining kills them.
- Bold your top 3–5 across groups and say why they win on the axes.
- Finalists get a comparison table: Memory / Meaning / Range scored ✓✓ (strong), ✓ (adequate), — (weak), with tradeoffs stated plainly.

**When the user pushes back or stalls** (wants a safe name, demands the .com, polls the whole company, freezes on the decision): consult `references/masters.md` and answer with doctrine, not accommodation.
