# Evaluation: Cutting, Scoring, and Testing Names

Load this file during Distillation (Phase 3) and Validation (Phase 4). Source: guide §3–4 (PDF pp. 20–26), competitor map §1.6.2 (PDF pp. 14–15).

Sentimentality is the enemy of good judgment. Evaluate against the orientation compass, not vibes.

## The six dimensions (§3.1, PDF pp. 20–21)

Screen every nominated candidate:

| Dimension | Question | Touchstones |
|---|---|---|
| **Depth** | Layers of meaning? Metaphorical weight without being cumbersome? | Virgin = rebellion; Amazon = boundless scale |
| **Temperature** | Warm and inviting, or cold and distant — and which does the brief call for? | Mailchimp warm; Blackstone forceful; Anthropic high-brow warmth |
| **Voice** | Sound it aloud: crisp, flowing, or friction? Rhythm? | Zoom is quick; Etsy is cute; SpaceX-style contractions add rhythm |
| **Visual** | Works in ALL CAPS, lowercase, tiny app icon, billboard? | SONOS is an ambigram; HP tightened Hewlett-Packard |
| **Differentiation** | Stands out from the competitor map? Trademarkable? | Snowflake amid Cloudera/MongoDB |
| **Special Wrongness** | Unforgettable newness — 1+1=3? Could it start a trend? | Teenage Engineering, The Browser Company of New York |

## Memory / Meaning / Range (§3.2, PDF p. 21)

The core scoring axes:

- **Memory** — remembered after one encounter? Spellable without asking? Sticks, or slides out?
- **Meaning** — connects emotionally, not just literally? Would the founder be excited to say it every day?
- **Range** — grows with the company, or traps it in one category?

Worked example (corporate cards):

| | Memory | Meaning | Range |
|---|---|---|---|
| **Mercury** | ✗ too common, diffused recall | ✓ god of commerce | ✓ scales, though rooted in commerce |
| **Ramp** | ✓ short, punchy, distinctive | ✓ suggests acceleration | ✗ anchored to finance/ops |
| **Brex** | ✓ angular letterform aids recall | ✗ synthetic, generic fintech | ✓ arbitrary form is free to evolve |

**Rule: 2 of 3 = viable. 3 of 3 = rare and magical. 0–1 = cut.**

## Sound symbolism (Lexicon)

Placek's linguists spent decades and millions researching how phonemes carry meaning across cultures — letters create psychological vibrations before semantics kick in. Use both to evaluate voice and to steer generation:

| Sound | Carries | Examples |
|---|---|---|
| **B** | reliability, dependability | BlackBerry (double B), Bose |
| **V** | vibrancy, daring, aliveness | Viagra, Corvette, Vercel |
| **Z** | speed, attention-grabbing | Zoom, Azure |
| **X** | innovation, edge | SpaceX, Xerox |
| **P, T, K** (plosives) | punch, impact | Pentium (deliberately potent) |
| Vowel ending | open, light | Carta, Figma |
| Hard-stop ending | punchy, decisive | Ramp, Check |

## Phonetics fast-pass (§4.3.4, PDF p. 25)

- **Phone test**: say it over the phone; can the listener spell it back and guess what the company does? Failures create customer-service problems forever. Also have Siri/voice agents read it aloud.
- **Homophones & mishear risk**: sight/site collisions; run the phone-spell test.
- **Consonant clusters**: at most one cluster like *str* or *ndr*.
- **Look-alike glyphs**: avoid l/1/I, O/0, rn/m, vv/w — they collide in UI and all-caps.
- **Sibilants vs. plosives**: too much sh/zz hisses; p/t/k/b/d/g add punch. Balance.
- **Open vs. closed ending**: match tone (see table above).

## Reality checks (§3.3, PDF p. 22)

Run before anyone falls in love:

1. **Legal scan** — three minutes on USPTO.gov / TMView for identical marks in the relevant class. Obvious conflict = kill now; real lawyers come later.
2. **Language check** — say it aloud ten times; check slang dictionaries; translate into key languages. Could it embarrass somewhere important?
3. **Landscape check** — plot on the competitor map. Camouflage or contrast? Adjacent companies with similar names?

Most names fail for boring reasons: hard to spell over the phone, unfortunate in another language, sounds like the market leader. Note problems without auto-eliminating — some are fixable with spelling changes or an added word.

## Testing with humans (§4.1–4.2, PDF pp. 23–24)

The agent can't run these directly — equip the user with exact protocols:

**8-second test** (don't skip, even under time pressure): black-and-white slide, big name, one-line description. Show for 8 seconds to 5–8 people per name (mix ideal customers and smart outsiders). Ask exactly: *"What do you expect from a company named ___?"* Record their first sentence verbatim — no paraphrasing, no helping. Afterward, ask them to recall all names; note stumbles and blanks. Compare impressions against the orientation feeling: if you marked Momentum and people say "feels expensive and fancy," reassess.

**Stack-rank polling**: rate each name 1–5, then rank all names most-to-least *interesting* (leave "interesting" undefined). Look for consistent top-3 finishers. **Polarization is a good sign — love/hate beats universal indifference.** Names everyone forgets get eliminated immediately.

**Placek's competitor test**: ask "Our competitor just launched under this name — what's your reaction?" Envy reveals market strength better than "do you like it?"

**The ice-cream caveat (A Hundred Monkeys)**: don't crowd-source the decision. Groups don't agree on what's interesting; they agree on what's easy to agree on. Polls inform; they never decide.

## Funnel targets

- After nomination + six-dimension screen + reality checks: **12–15 viable names** (§3.4). Fewer than 10 → return to Exploration. More than 20 → raise standards.
- After validation and diligence: **3–5 finalists** (§4.5, PDF p. 26). Fewer than 3 solid options → go back. Don't settle; the next decade depends on it.
