# The Masters: Judgment Calls and Objection Handling

Load this file when the process stalls on human factors — a hesitant team, a bikeshedding committee, a founder chasing a perfect .com — or when you need a tiebreaker grounded in professional naming doctrine. Three schools, distilled from Willem Van Lancker (Terrain, Onym; author of the bundled guide), David Placek (Lexicon Branding: BlackBerry, Pentium, Swiffer, Sonos, Azure, Vercel, Windsurf, Impossible Foods), and A Hundred Monkeys (Eli Altman, *Don't Call It That*).

## Situational counsel

| Situation | Counsel | School |
|---|---|---|
| Team gravitates to the safe, comfortable option | Comfort is a warning sign. If everyone's comfortable, you probably don't have the right name yet. Great names generate initial resistance — Azure was called dumb, BlackBerry crazy. | Placek |
| Feedback splits the room | Polarization signals energy, not failure. When Intel's committee split over Pentium vs. "Pro Chip," Andy Grove read the tension as validation. Love/hate beats indifference. | Placek |
| "I'll know it when I see it" | You won't. In ~4,000 Lexicon projects, the instant aha essentially never happened. Judge against orientation criteria, not goosebumps. | Placek |
| "Let's poll everyone / run a big focus group" | Groups don't agree on what's interesting; they agree on what's easy to agree on. Structured tests inform (8-second test, stack-rank); crowds never decide. | A Hundred Monkeys |
| "The .com is taken, kill the name" | The .com is an area code, not the address. Square lived on squareup.com for years. Use modifiers/TLDs now, negotiate the purchase later. Never let domain inventory pick your name. | Placek + Van Lancker |
| Name feels "too weird" | The easier a name is to spell, pronounce, and file away, the easier it is to forget. Great names have nerve, ambition, and personality — they take risks. In consumer categories, safe names are bland; winners leap off the shelf. | A Hundred Monkeys |
| Name requires explanation, team worried | A name shouldn't close the sale; it should **start a conversation** — provoke the question that lets you tell the story. Distinguish "needs a story" (good) from "needs an apology" (bad). | A Hundred Monkeys |
| Everything generated sounds like the category | Run oblique briefs: name a fake product in another category that shares the feeling (Windsurf came from a blind "flow" brainstorm). Escape the category's vocabulary gravity. | Placek |
| Descriptive candidate on the table | Descriptive optimizes the first conversation and handicaps every one after; it's also nearly impossible to protect. If you must be descriptive, execute with wit — don't be Mailboxes Etc. | Van Lancker + A Hundred Monkeys |
| Committee is stuck / bikeshedding | Buy-in to the process creates buy-in to the result — restate the orientation criteria and score against them. Then: one owner decides. Clarity beats consensus. | A Hundred Monkeys + Van Lancker |
| Founder anxious after deciding | Predictable psychology, not a signal. See "Handling regret" in `finalization.md`. | Van Lancker |
| "Naming feels like a cosmetic detail" | Naming is compounding leverage: a distinctive name accrues mental equity with every utterance, type, and search — asymmetric advantage that starts before any marketing spend. | Placek |

## The three schools in one line each

- **Van Lancker — naming is positioning.** You aren't choosing a word; you're detailing the tone, personality, and story of the brand, from which a name emerges. Method: orient → explore in volume → distill ruthlessly → validate strategically → one person commits → steward forever.
- **Placek — naming is science plus nerve.** Sound symbolism (letters carry psychological vibrations pre-semantically), engineered volume (1,000+ candidates, parallel blind teams), and the discipline to choose the uncomfortable, distinctive option over the likable one.
- **A Hundred Monkeys — naming is writing.** Names are the tip of a voice; they should have a point of view, earn attention, and start conversations. Distrust trends (dropped vowels, -ly/-ify suffixes), empty tech-sounding coinages, and consensus.

## Placek's Diamond (orientation aid)

When a user can't articulate what the name must do, draw the diamond — four points:
- **Top — the win**: what does success look like?
- **Right — what we have** to win with (assets, story, proof)
- **Bottom — what we need** that's missing
- **Left — what we must say**: the core message

Breakthrough names come from mapping behavior and experience, not from hunting words. Feed the answers back into Purpose / Promise / Feeling.

## Two forces to balance (Van Lancker, §2, PDF p. 16)

- **Ego** wants ambitious, clever, impressive — a name to satisfy vanity for decades.
- **Logic** wants clear, direct, sufficient — easy to say, remember, type.

Tesla threads it: visionary enough for grand ambition (ego), crisp and pronounceable worldwide (logic). Use the pair as a diagnostic when a shortlist skews all-clever or all-plain.
