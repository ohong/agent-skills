## Blender engineering references

Consult documentation matching the installed version before implementation. During research, direct fetches returned errors; indexed official text supplied the following findings. Development documentation can change.

- **Packed data:** packing has resource-type limits; pack and then save. [Source](https://docs.blender.org/manual/nl/5.0/files/blend/packed_data.html)
- **Blender 5.0 core changes:** embedded linked data can remain linked and is not thereby locally editable. [Source](https://developer.blender.org/docs/release_notes/5.0/core/)
- **Action slots:** modern action association needs version-aware handling. [Source](https://docs.blender.org/api/dev/bpy.types.ActionSlot.html)
- **glTF exporter:** supported animation channels, material constraints, and action grouping require verification in the installed exporter and target consumer. [Source](https://docs.blender.org/manual/en/dev/addons/scene_gltf2.html)
